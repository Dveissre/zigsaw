# 试炼退役规则

本目录是试炼制限规则的唯一归档入口。

## 约定

- 运行时只读取 `public/data/trial-rules.json`。
- 退役规则不得存在于运行时规则表中，也不得出现在调试制限选择器里。
- 每条退役规则使用固定三件套：
  - `<id>.rule.json`：退役时的完整规则定义快照。
  - `<id>.md`：退役原因、已实现行为和休眠代码索引。
  - `<id>.svg`：规则图标。
  - `<id>.css`：可选；只用于该规则的休眠视觉实现，不得被运行时加载。
- `registry.json` 是退役规则的统一索引；新增、恢复或永久删除规则时先更新这里。
- 代码和测试可以作为休眠实现保留，但不得存在无需显式归档数据即可进入的运行时路径。
