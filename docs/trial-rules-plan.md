## 规则目录原则

- `id` 是永久稳定键，不能跟随显示名变化。
- 中文名、英文名、图标和公开说明是显示数据，与效果配置分离。
- “奇境”和“厄境”是规则家族，不是可游玩的独立规则。
- 家族整体占用一个抽取名额，再在家族内抽取具体变体。
- `internalNotes` 只供开发和维护使用，不进入游戏 UI。
- `presto` 的正式显示名已统一为“急板”，稳定 ID 仍为 `presto`。

## 数据层 v2

规则 JSON 已升级为 v2，并由 `src/game/trial-rules.ts` 做运行时校验。新增规则
必须使用同一结构，不得把说明、选池条件和判题策略继续写死在 UI 或
`submit()` 分支中。

### 规则定义

```text
TrialRuleDefinition
- id
- name / english
- description.public / description.internal
- stars
- icon
- family?: { id, weight, variantWeight }
- timing: { normalSeconds, bossSeconds, normalMultiplier, bossMultiplier,
  sharedBudgetSeconds?, correctBonusSeconds? }
- selection: { normal: { partLengths, partWeights?, partWeighting?,
  partLengthProgression? }, excludedComponents?,
  boss: { answerCount, partLengths, totalParts } }
- policy.prompt.normal / policy.prompt.boss
- policy.answer.normal / policy.answer.boss
- policy.cards.normal / policy.cards.boss
```

`policy.cards.*` 目前支持 `display: "obscured"`、`obscureAfterMs` 和
`obscureCount`（正整数或 `"all"`）。计时使用累计有效答题时间，暂停不推进。
还支持 `decoyCount` 与 `decoyComponents`：在不参与判题的卡片槽中加入指定
类别的干扰卡；BOSS 判题允许 `mustIgnore` 卡剩余。

### 展示卡

```text
TrialCard
- uid
- symbolId
- components?: number[]
- source: answer | decoy | inherited | wildcard
- quantity?
- remainingQuantity?
- obscuredAtMs?
- obscured?
- mustIgnore?
- displayGlyph?
- displayMode?
```

这用于支持复合卡、复沓卡、白板、翻黑和跨题继承。DOM 中不得输出被隐藏卡的
真实 `symbolId`、名称或无障碍标签。

### 题目计划

```text
StagePlan
- normalQuestions[8]
- bossQuestion
- timingBudget
- carryState
- uniqueAnswerPolicy
```

`TrialQuestionState` 应同时包含：

- 标准答案规格与可接受答案集合。
- 实际展示卡。
- 必须消耗的卡及允许剩余的卡。
- 当前规则状态。
- 时限与定时遮挡事件。

### 判题器

判题结果至少包含：

```text
displayAnswer
accepted
consumedCards
remainingCards
answerDetails[]
```

新增规则不得继续在 `submit()` / `submitBoss()` 内堆叠专用分支。

### 阶段选规则

正式排期：

- 第一幕：无制限。
- 第二、三幕：一星。
- 第四、五幕：二星。
- 第六幕：二星或三星随机。
- 第七幕：三星。

奇境整体与其它一星规则等权；厄境整体与其它二星规则等权。

当前 `/test/` 为便于覆盖已有规则，暂时排为：

1. 无制限
2. 四分法
3. 急板
4. 极简主义
5. 短视
6. 繁缛
7. 心盲症

第 4 幕当前使用一星规则只是测试页过渡编排；规则实装完成后必须回到上面的
正式排期。

调试解锁后，阶段开始页可把当前幕强制切换为任意已登记规则。覆盖写入
`TrialState.forcedRuleId`，不修改 `stageAssignments`；进入下一幕时自动清除。

## 详细规则规格

### 无制限 / Unbound / 0 星

- 公开说明：不附加额外规则。
- 普通题：每幕 8 题；从试炼默认题库按二至多部件字权重抽取；30 秒。
- BOSS：两个不同答案；总部件数 6–8；90 秒。
- 选池：不额外过滤一、二级字和可渲染拆法。
- 本规则只定义默认值，不应覆盖全局试炼题干、结算与暂停规则。

### 急板 / Presto / 1 星

- 公开说明：作答时间缩短至三分之二。
- 普通题：题数、题库、选池和 BOSS 结构均与无制限相同；时限 20 秒。
- BOSS：两个不同答案；总部件数 6–8；时限 60 秒。
- 暂停罚时、答后揭示和幕间暂停逻辑保持全局规则。
- 正式显示名是“急板”；`presto` 是永久 ID。

### 极简主义 / Minimalism / 1 星

- 公开说明：作答时间减半；仅出现二、三部件字。守幕关卡以六个部件组成三个字。
- 普通题：只从二、三部件字中抽取；二部件与三部件各占 1:1；15 秒。
- BOSS：三个互不相同的二部件答案；共 6 张卡；45 秒。
- 选择二、三部件时仍须遵守“可实现拆法”和试炼一二级范围过滤。
- 答对后的揭示、暂停和结算动画不改变本规则的题库条件。

### 繁缛 / Compages / 2 星

- 公开说明：作答时间不变；仅出现五部件及以上的字。守幕关卡以十个部件组成
  两个五部件字。
- 普通题：只从五部件及以上字抽取；按可用字/拆法池加权，避免七至十字因
  小池而被异常放大；30 秒。
- BOSS：两个不同的五部件答案；共 10 张卡；90 秒。
- 若某幕可用长字不足以填满 8 题且不重复，进入该幕前直接报题库不可用，
  不允许退回普通题库。

### 失与得 / Reschedule / 1 星

- 公开说明：整幕共享 150 秒（含守幕关卡）；答对后保留剩余时间并加 5 秒，
  总时间最多 150 秒。暂停扣除 15 秒。
- 每幕开始时把共享池重置为 150 秒；普通题与 BOSS 均消耗同一个池。
- 答对普通题或完整答对 BOSS 后，下一题以“实际剩余秒数 + 5”继续，且封顶
  150 秒；部分答对 BOSS 不单独加时。
- 答错或时间归零结束整次试炼；答对不会恢复到默认 30/90 秒。
- 暂停固定扣 15 秒，最低扣到 0；不再使用测试环境的剩余时间减半。
- 表现：答对后倒计时圆环从当前进度向较长的剩余时间恢复，而不是瞬间跳值。

### 枝指（暂命名） / Polydactyly / 3 星

- 状态：已实现；可通过阶段页调试制限选择器进入。
- 公开说明：道中关卡多出 1 张常用干扰卡，守幕关卡多出 2 张；这些卡不应参与
  答案。
- 干扰卡必须来自 N 稀有度常用部件，并标记为 `mustIgnore`。
- 原答案拆法为 `A+B+C`、干扰卡为 `D` 时，只禁止 `A+B+D`、`A+C+D`、
  `B+C+D` 形成任何合法答案；`A+D`、`B+D`、`C+D`、`D` 等较小组合不受
  此检查限制。四部件答案同理，只检查移除一个原部件后补入干扰卡的三部件
  组合。题目本身原有的 anagram 不因此变成额外干扰。
- 普通题与 BOSS 都必须预先通过“卡片子集唯一答案”检查；不能先在运行时
  发现问题再重抽。
- 判题允许干扰卡剩余，不计入答案消费；题面必须明确告知玩家忽略干扰卡。
- 干扰卡只从图鉴 N 级部件中选取，并按关联汉字数加权；更高频部件更常出现，
  但不会固定为唯一最常用部件。
- 未揭示时干扰卡不增加任何样式、角标或文字提示。

### 拾级 / Anabasis / 1 星

- 状态：已实现；可通过阶段页调试制限选择器进入。
- 公开说明：八个道中关卡的部件数从 2 逐步增加到 7 或 8；守幕关卡用十张卡组成
  两个汉字。
- 普通题：严格八题；部件数序列起点为 2、单调不下降、终点为 7 或 8。
- 终点为 7 时，七次转移中有 5 次 `+1`、2 次不变；终点为 8 时，有
  6 次 `+1`、1 次不变。具体停留位置随机，但必须先验证整条路径的题库。
- 终点不是等概率：先按 7/8 各自当前可用答案数加权。之后枚举该终点下的
  全部停留位置方案，并按每个“被额外重复一次的长度”的当前可用答案数加权。
  因此答案池越大的长度越容易被停留，7/8 的总体频率也会随实际池体量变化。
- BOSS：共 10 个部件，可任意分给两个不同答案，不强求各五部件；两个答案
  的部件数之和必须恰好为 10。
- 同一幕不得重复使用同一答案；若抽取到的路径末端没有足够 7/8 部件字，
  进入该幕前报题库不可用。
- 当前池足够单次使用：7 部件 69 字、8 部件 18 字；末端题只出现一次。
- 最近使用过的 12 个 7/8 部件汉字的记录会保存在本地；后续游玩优先排除
  这些汉字，候选全部耗尽时才回退到完整池。

### 四分法 / Tetrarchy / 1 星

- 公开说明：道中关卡只出现四部件字；守幕关卡为两个四部件字。作答时间不变。
- 普通题：只从四部件字中抽取；每题展示恰好 4 张部件卡；30 秒。
- BOSS：两个不同答案；每字固定 4 部件；共 8 张卡；90 秒。
- 判题仍使用兼容层可接受答案；不能因为“四分法”而只接受数据中的首选拆法。
- 当前运行时数据：`public/data/trial-rules.json` 的 `tetrarchy` 项。

### 短视 / Myopia / 2 星

- 公开说明：道中关卡开始 2 秒后随机遮挡 1 张部件卡；守幕关卡开始 2 秒后遮挡
  2 张。
- 遮挡对象在出题时从题面实际卡片中随机选择；本题内保持不变。
- 翻黑发生在累计有效答题时间达到 2 秒后；暂停期间该累计时间冻结。
- 卡片保留原槽位和尺寸，只把可见面替换为暂停时的黑色卡背；已消耗卡不参与
  遮挡抽取。
- 暂停会把其余卡也暂时翻黑，但恢复后只有原本达到时限的卡继续保持黑面；
  已经翻黑的卡不会因暂停或继续而恢复。
- 翻黑卡不显示文字、不可选中或复制，也不接受点击；其部件 ID 仍保留在判题
  状态中，可正常参与组字和答案消费。
- 已消耗卡不再显示，因此不会被后续遮挡事件重新选为可见目标。

### 心盲症 / Aphantasia / 3 星

- 公开说明：道中关卡开始 4 秒后遮挡全部部件卡；守幕关卡开始 10 秒后遮挡全部。
- 遮挡前玩家可正常读题；时间事件由题目开始计，不包含答后揭示和幕间动画。
- 与短视共用遮挡状态和黑卡视觉，不新增第二种遮挡表现。
- 暂停冻结事件；恢复后已经翻黑的卡不还原，尚未翻黑的卡正常恢复。
- 翻黑卡仍参与组字与答案消费，但不可读取、选择或复制。

### 预制件 / Prefabrication / 2 星

- 状态：已实现；可通过阶段页调试制限选择器进入。
- 公开说明：道中关卡会把两个部件预组为一个黄色汉字卡；守幕关卡进行两次
  预组，取件可以跨两个答案。同一个预组汉字每幕只能出现一次。
- 普通题：答案至少 3 部件；从答案拆法中选取一对能直接组成另一个汉字的
  部件，替换为一张黄色复合提示卡，其余答案部件保持原样。答案仍按原字提交。

  读音均可。守幕关卡可逐字提交，或用空格分隔同时提交。答案揭示时显示带调
  拼音。
- 普通题：题目选择、显示卡和答案字保持不变；接受拼音库中的任一读音。
- BOSS：可逐字提交一个拼音，或用空格一次提交多个拼音；同时提交时允许按
  不同答案顺序解析。
- 输入规范化：大小写不敏感，`ü/v` 等价，去声调后与 `plain` 读音比较。
- 答案揭示：使用 `marked` 带调拼音；多音字以 ` / ` 分隔，并在答案字上方
  显示。

### 奇境家族 / Byland / 1 星

状态：五个变体均已实现；英文显示名暂时统一为 `Byland`。

五个变体分别使用以下干扰类别：

- 涉沧澜：水、氵、冫、雨。
- 披丛莽：艹、屮、木、禾。
- 临岩岫：土、石、山。
- 徕远客：人、亻、彳。
- 听浮嚣：口、讠、耳。

每题加入 1 张干扰卡，并在题面说明当前奇境使用的类别。具体变体共享一个
一星抽取名额。

实现约束：

- 普通题增加 1 张干扰卡；BOSS 增加 2 张互不相同的同类干扰卡。
- 所有候选拆法必须完全排除当前变体的全部成员，而不是只排除本次抽到的
  干扰部件。例如涉沧澜中，即使干扰卡是 `氵`，含有 `雨` 的拆法也不得出题。
- 干扰卡必须属于当前变体列出的类别，且只作为额外卡出现，不改变答案拆法。
- 允许“干扰卡 + 答案卡子集”形成其他合法汉字；若玩家提交这些字，应按错误
  处理，不再因此换干扰卡或换题。
- BOSS 判题只接受本题抽出的目标答案；干扰卡标记为 `mustIgnore`，可以剩余，
  不能让玩家为了完成 BOSS 强行消费干扰卡。
- 公开说明需要写明本题会出现的干扰类别，不能只说“忽略干扰”。

### 厄境家族 / Outland / 2 星

五个变体与奇境使用相同五类部件。干扰部件附着到题目至少一个部件上，形成
新的复合提示字形；同一基础部件可以有多个附着方式，也可同时附着多个部件。

例：水系厄境中，木可形成 `沐` 或 `霂`；木系厄境中，木也可形成 `林`。
该规则已通过拆法层可生成性检查，但实装前仍需检查目标复合字的字体和布局。
厄境五个变体共享一个二星抽取名额。

实现约束：

- 每题至少选择一个答案部件，将一个或多个当前变体类别的干扰部件附着到它
  上面，以新的复合字形作为显示卡。
- 同一基础部件可以对应多个复合结果；例如水系中 `木` 可分别显示为 `沐`
  和 `霂`，木系中 `木 + 木` 可显示为 `林`。
- 判题仍使用原答案部件与原拆法；复合字形只改变展示，不代表答案变成结果字。
- 复合字形材料必须可定位到具体基础组件组合；DOM 不得暴露被遮挡的原始部件名。
- 五类候选池已确认满足可生成性：共有 1754 条基础部件 + 干扰类别的复合
  方式；这不等于所有复合字形都能在现有字体中清晰排版，实装前仍需抽样渲染。

## 已知缺陷与待决问题

### 时间与状态

- 短视、心盲症已明确：暂停冻结事件；翻黑卡仍参与判题，但不可读取或操作。
- 拾级需要整幕预生成单调序列；终点 7 有两次停留，终点 8 有一次停留。

### 唯一答案

- 通配符、枝指、回声室应共用同一套答案兼容搜索器；格式塔使用预生成的
  直接拆法答案池，不参与该兼容层搜索。
- 唯一性判断按唯一答案字符计数；多个拆法指向同一答案时只能计一次。
- 干执卡本身若与答案部件组成另一字，应判错还是禁止出现，需要统一。

### 词语

- 构词法直接采用 [words_2to4.txt](words_2to4.txt) 的完整词表；之后调整收录
  边界时应重新生成 `public/data/composition-words.json`。
- 半韵法已从同一词表生成独立池，并固定跨字复沓压缩和隐藏显示规则。

### 字形与映射

- 三秋树已使用 `tongyong12_trad.json`；后续补充异体字时仍需沿用同一筛选规则。
- 化约论的展开来源记录在题目状态与历史中；卡面只显示展开后的普通部件，
  不显示来源提示。预制件、厄境仍需各自的复合展示卡。
- 厄境当前统计只能证明“基础部件 + 干扰部件可形成该字”，不能证明该视觉
  组合在排版和字体上都可读，实装前需抽样渲染验证。

### 数量卡与跨答案

- 复沓卡必须允许部分消费并跨 BOSS 的两个答案使用。
- 需要区分“同一数量卡的剩余份数”和“答案中本来就有多个独立同名部件卡”。

### 规则家族

- 奇境、厄境的家族概率必须只占一个名额。
- CSV 中的两个组标题不是可游玩规则，不应进入运行时规则列表。
